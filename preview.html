▶️ 启动方式

方式 1：一键启动 (Windows)

cd grw-workspace
start.bat

方式 2：手动启动

# 后端
cd backend
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py

# 前端（新窗口）
cd frontend
npm install
npm run dev

访问 http://localhost:5173/ 即可使用
